# CampusWheels

This project is for my Object-Oriented Programming assignment. It models a simple campus vehicle-rental system using Python classes.

## Files

* `rental.py` — contains the `Vehicle`, `Renter`, `ElectricCar`, and `Motorbike` classes.
* `main.py` — demonstrates how the classes work.

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

## AI Use

I used ChatGPT as a learning assistant while working on this assignment.

For `rental.py`, I wrote the code step by step while ChatGPT explained concepts such as classes, `__init__`, `__str__`, properties, setters, inheritance, `super()`, and polymorphism. ChatGPT also helped me identify and fix syntax and indentation mistakes.

For `main.py`, ChatGPT helped me draft the demonstration code. I reviewed the code and used it to understand how the classes are created, how renting and returning work, how `ValueError` is caught, and how polymorphism works with different vehicle types in the same list.

I used ChatGPT mainly for explanations, guidance, debugging, and understanding the object-oriented programming concepts used in the assignment.
